# WiFi

Cadmus can turn WiFi on when something needs the network, then turn it off again
when it is idle.

## Modes

Open the **WiFi** control in the top menu and choose one of:

- **Off** — WiFi stays off. Features that need the network cannot turn it on
  automatically; you must turn WiFi on yourself beforehand.
- **Always On** — WiFi stays on.
- **Auto** — Cadmus turns WiFi on when something needs the network, then powers
  it down after a period of inactivity.

## Idle timeout

When WiFi is set to **Auto**, Cadmus waits a short time after the last network
use before powering the radio down. Change that delay in the
[settings editor](ui/settings/index.md).
