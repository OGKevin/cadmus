# Architecture Decisions

Architecture Decision Records (ADRs) record decisions that are hard to reverse,
surprising without context, and the result of a real trade-off. Each ADR says
what was decided and why, so later changes do not undo it by accident.

New ADRs take the next free number: `NNNN-short-slug.md`.
